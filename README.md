# 香港急症室輪候時間地圖 (AE-Waiting-Time-Map)

香港醫院管理局 18 間急症室即時輪候時間地圖。

🔗 Live: https://hkteddychan.github.io/AE-Waiting-Time-Map/

## 功能

- 🏥 **即時輪候地圖**：18 間公立醫院急症室，顏色按輪候長短分級，彈窗顯示 T1/T2/T3/T4/5 各分流中位數與 75th
- 📊 **輪候歷史趨勢**：本機 localStorage 累積每約 4 分鐘一筆的歷史快照（保留 24 小時），彈窗顯示 T3 中位 sparkline
- ⚖️ **多醫院對比**：清單每行「+」加入對比（最多 6 間），底部對比 bar 開啟橫向比較表，含各分流中位數 + 趨勢圖
- 🌙 **高峰期提示**：依時間/週末自動提示繁忙時段（晚間高峰、週末門診休診等）
- 🔁 **自動刷新**：每 30 秒自動更新，附倒數計時；失敗保留上次資料並標示「可能過時」
- 📴 **離線 / PWA**：manifest + Service Worker，可加到主畫面；離線時顯示上次數據並顯示離線 banner
- 📍 **定位 + 距離**：自動計算你與各醫院的距離並排序
- 🔍 **排序**：按 T1/T2/T3/T4/5 分流排序（短→長 / 長→短）

## 資料來源

| 項目 | 來源 |
|------|------|
| 急症室輪候時間 | 醫管局 HA Open Data `https://www.ha.org.hk/opendata/aed/aedwtdata2-en.json`（欄位含 t1wt, t2wt, t3p50, t3p95, t45p50, t45p95）|
| 醫院座標 | `hospitals.json`（本地檔）|
| 地圖底圖 | OpenStreetMap |

> ⚠️ 趨勢圖為**本機累積的歷史數據**（非官方），首次使用後需持續開啟一段時間才有資料。官方只提供「現在」的即時數值，無公開歷史 API。

## 本機執行

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

純靜態網頁，無需後端。部署到 GitHub Pages 即直接可用的 PWA。

## 未做事項 / 已知限制

- 歷史趨勢只存在本機（localStorage），換裝置/清瀏覽器資料會重置
- HA API 偶發逾時（10 秒），已降級顯示上次資料
- 高峰提示為固定時段規則（晚間/週末/深宵/午間），未做歷史統計優化
